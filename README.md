# finscope-backend

A lightweight Express/Node.js backend prototype explored during the Finscope project.
Development stopped at the prototyping stage and the project is **archived and no longer
maintained**; it has been superseded by the
[finscope-ai-research](https://github.com/aydinmonavvari/finscope-ai-research) research
portfolio, where the same ideas were rebuilt as a reproducible Python research workbench.
This repository is kept public for transparency/history only and does not represent
finished or supported software.
